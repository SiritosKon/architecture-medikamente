## Слои защиты

Защита не встраивается в каждый сервис отдельно, а вынесена в общие слои. Любой новый сервис или партнёр подключается через них и сразу получает защиту, поэтому новые интеграции не нужно заново проверять.

| Слой | Блоки | Что даёт |
|---|---|---|
| Доступ | API Gateway, Keycloak, OPA, Partner API | Единый вход с MFA. Права по роли и атрибутам: филиал, лечащий врач, пациент видит только себя |
| Защита данных | Vault, согласия, удаление по запросу, каталог данных | Шифрование и токены вместо ФИО, согласия по целям, удаление данных по запросу, теги на полях |
| Контроль | Журнал аудита, SIEM, DLP, проверка релиза | Кто и что смотрел, алерты на нетипичный доступ, запрет утечек, проверка тегов при каждом релизе |
| Аналитика | Обезличивание, озеро данных, BI / ML | Аналитика и ML работают только с обезличенными данными |

## Аналитический слой

Данные из рабочих баз попадают в аналитику только через обезличивание:
- ФИО и контакты удаляются;
- ID заменяется псевдонимом;
- дата рождения превращается в возраст, адрес — в город;
- редкие сочетания признаков скрываются (k-анонимность).

## Домены данных и доступ (MVP)

| Домен | Данные | Кто имеет доступ |
|---|---|---|
| Пациенты | ФИО, дата рождения, контакты | Пациент — свои. Ресепшен — своего филиала, в маскированном виде |
| Запись | Слот, врач, филиал (без ФИО) | Пациент — свои записи. Ресепшен — свой филиал. Врач — свои пациенты |
| Уведомления | Дата и время приёма | Только сервис уведомлений, при согласии пациента |
| Согласия | Цели, сроки, отзыв | Пациент — свои. Ответственный за ПДн |
| Медкарта (финал) | Диагнозы, заключения | Только лечащий врач. Пациент — свои документы |
| Анализы (финал) | Результаты | Лечащий врач, пациент. Лаборатория — только свои заказы, без ФИО |

Роли (RBAC) определяют, к какому домену у сотрудника есть доступ. Атрибуты (ABAC) сужают доступ до конкретных записей: филиал, лечащий врач, пациент = владелец данных.

## MVP и финальное состояние

**MVP (через 2 месяца):**
- портал записи и портал сотрудников;
- сервисы записи, пациентов и уведомлений;
- из слоёв защиты: вход, права, шифрование, согласия, журнал аудита.

**Финал (через год):** добавляются мобильное приложение, медкарта, лаборатория, оплата, удаление по запросу, каталог данных, SIEM, DLP, проверка релиза и аналитика.
