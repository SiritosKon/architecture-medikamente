## Главное

1. Медицинские данные (спецкатегория ПДн и врачебная тайна) лежат в открытых файлах. Доступ не разграничен, аудита и шифрования нет.
2. Диагноз можно понять и косвенно: по записи к врачу-специалисту, по услуге в чеке, по списанию препарата на пациента.
3. Удалить данные пациента по запросу невозможно: неизвестно, где лежат копии.
