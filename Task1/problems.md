# Аудит и проблемные зоны

**С чем сверяли:**
- законы: 152-ФЗ (персональные данные), 323-ФЗ (врачебная тайна);
- уровень защищённости: ПП-1119 определяет его, приказ ФСТЭК № 21 задаёт меры;
- принципы: Privacy by Design, Data Minimization, Data Lineage.

**Уровень защищённости.** Компания обрабатывает данные о здоровье. Сейчас достаточно УЗ-3. После пятикратного роста пациентов станет больше 100 тыс., и понадобится УЗ-2. Целевую систему проектируем сразу под УЗ-2.

Критичность: 🔴 высокая, 🟠 средняя, 🟡 низкая.

## Что улучшить

| Проблемы | Решение |
|---|---|
| P-01, P-16 | Классифицировать данные, составить модель угроз, оформить документы по 152-ФЗ, назначить ответственного за ПДн |
| P-02, P-08, P-09 | Перенести данные из файлов в СУБД в защищённом контуре, включить шифрование, делать бэкапы на резервную площадку |
| P-03, P-15, P-18 | Единый вход с MFA; доступ по ролям и атрибутам (филиал, лечащий врач) |
| P-04, P-22 | Журнал аудита, SIEM, алерты на нетипичный доступ |
| P-05, P-06, P-21 | DLP; результаты выдавать только через личный кабинет |
| P-07, P-23 | Единая система вместо Excel |
| P-11, P-12, P-13 | Сервис согласий, сроки хранения, каталог данных с Lineage |
| P-14, P-17 | Аналитика и лаборатория работают только с обезличенными данными |
