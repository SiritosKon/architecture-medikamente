# Аудит и проблемные зоны

**С чем сверяли:**
- законы: 152-ФЗ (персональные данные), 323-ФЗ (врачебная тайна);
- уровень защищённости: ПП-1119 определяет его, приказ ФСТЭК № 21 задаёт меры;
- принципы: Privacy by Design, Data Minimization, Data Lineage.

**Уровень защищённости.** Компания обрабатывает данные о здоровье. Сейчас достаточно УЗ-3. После пятикратного роста пациентов станет больше 100 тыс., и понадобится УЗ-2. Целевую систему проектируем сразу под УЗ-2.

## Что улучшить

| Проблемы | Решение |
|---|---|
| Нет классификации и документов по ПДн | Классифицировать данные, составить модель угроз, оформить документы по 152-ФЗ, назначить ответственного за ПДн |
| Данные в открытых файлах, один сервер | Перенести данные из файлов в СУБД в защищённом контуре, включить шифрование, делать бэкапы на резервную площадку |
| Доступ не разграничен, вход по паролю | Единый вход с MFA; доступ по ролям и атрибутам (филиал, лечащий врач) |
| Нет журнала и мониторинга | Журнал аудита, SIEM, алерты на нетипичный доступ |
| Бесконтрольные копии, почта, бумага | DLP; результаты выдавать только через личный кабинет |
| Двойной учёт, Excel не масштабируется | Единая система вместо Excel |
| Согласия, сроки хранения, копии | Сервис согласий, сроки хранения, каталог данных с Lineage |
| Полные ПДн у аналитика и лаборатории | Аналитика и лаборатория работают только с обезличенными данными |
