# architecture-medikamente

Проектная работа 10 спринта — кейс компании «Медикаменте» (защита конфиденциальных данных, Privacy by Design).

| Директория | Содержимое |
|---|---|
| [`Task1`](Task1/README.md) | Анализ безопасности текущего состояния: диаграммы потоков данных (DFD), список проблемных зон, данные для защиты, тегирование |
| [`Task2`](Task2/README.md) | C4 Context/Container целевого состояния (MVP) с блоками Privacy by Design и аналитическим слоем |
| [`Task3`](Task3/README.md) | Классификация данных, обоснование защиты, шифрование при хранении и передаче, реестр средств защиты |
| [`Task4`](Task4/README.md) | Диаграмма Исикавы (draw.io) по узким местам миграции и отчёт с рекомендациями |
