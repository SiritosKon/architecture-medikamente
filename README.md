# architecture-medikamente

Проектная работа 10 спринта — кейс компании «Медикаменте» (защита конфиденциальных данных, Privacy by Design).

| Директория | Содержимое |
|---|---|
| `Task1` | Анализ безопасности As-Is: диаграммы потоков данных (DFD), список проблемных зон, данные для защиты, тегирование |
| `Task2` | C4 Context/Container целевого состояния (MVP) с блоками Privacy by Design и аналитическим слоем |
| `Task3` | Классификация данных, обоснование защиты, инструменты шифрования at rest / in transit, реестр СЗИ |
| `Task4` | Диаграмма Исикавы (draw.io) по узким местам миграции и отчёт с рекомендациями |
